# Model picks

Turntable previews of generated 3D models, published by `tools/assetgen` in the WashingGame
project. Open the site, compare the candidates for each crop, tap a winner, and copy the text it
gives you back to the machine that generated them.

Everything under `docs/` is generated. Do not edit it by hand; run `assetgen.py site --push`.

Note that a GitHub Pages site is publicly readable even from a private repository.
